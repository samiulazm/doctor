<objective>
Add the login lockout pre-check to Auth::login() and raise the lockout_time config from 50 to 300 seconds (SEC-03).

Purpose: Ion Auth tracks failed attempts and enforces lockout during `ion_auth->login()` calls internally, but the Auth controller does not show the lockout message to the user before attempting the login. Adding the pre-check provides fast rejection without creating a DB attempt record and gives the user clear feedback. Raising lockout_time to 300s brings it above the OWASP-recommended minimum of 60s.

Output: Auth.php with is_time_locked_out() pre-check inserted before the ion_auth->login() call; ion_auth.php with lockout_time = 300.
</objective>
