<objective>
Migrate the OpenAI API key from the `settings` DB table to the `OPENAI_API_KEY` environment variable in all 4 consumer files, and add the `openai_api_key` config entry to `application/config/openai.php` (SEC-09).

Purpose: The key is stored in the `settings` table and read via `$settings->chatgpt_api_key`. Any code that can read the settings table (70+ modules) has access to the key. Moving it to an env var restricts access to code that explicitly reads it via the config, and enables standard key rotation practices.

Output: openai.php updated with the env-driven key config; 4 controllers patched to use `$this->config->item('openai_api_key')`; Patient.php also noted.
</objective>
