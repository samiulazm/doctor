<objective>
Patch the two highest-severity vulnerabilities in Api.php: the brute-forceable 4-digit API token (SEC-01) and the cross-tenant hospital_id GET override (SEC-02).

Purpose: These are CRITICAL issues. The API token space of 8,889 values is trivially exhausted in milliseconds. The unvalidated GET hospital_id allows any authenticated caller to read any tenant's patient list, diagnoses, symptoms, and treatment history.

Output: Api.php with `bin2hex(random_bytes(32))` tokens and session-derived hospital_id in all 6 affected endpoints.
</objective>
