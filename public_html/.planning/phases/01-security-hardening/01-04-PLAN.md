<objective>
Remove all four hardcoded `'12345'` password literals from the four controller files (SEC-06).

Purpose: `'12345'` is used as a default credential in new hospital registration (Frontend.php, Request.php), as a meeting room default password (Meeting.php), and as a PayU product_info placeholder (Payu.php). All represent either weak first-use credentials or credential-looking values that trigger security scanners.

Output: Four controllers with '12345' replaced by context-appropriate values (generated passwords for auth flows, empty string for PayU product metadata).
</objective>
