<objective>
Patch Inventory.php for two requirements: add the admin-only auth guard to init_categories() (SEC-10) and delete the debug methods testCategory(), debug_categories(), and the echo output inside init_categories() (SEC-07).

Purpose: `init_categories()` executes `DROP TABLE IF EXISTS inventory_categories` with no role check — any logged-in user (nurse, patient, receptionist) can wipe production data. The debug methods `debug_categories()` and `testCategory()` echo raw PHP structures to the browser. Both are in the same file, so they are patched in one plan to avoid file-ownership conflicts.

Output: Inventory.php with an `in_group(['superadmin','admin'])` guard at the top of init_categories(), all debug echo/print_r removed, and debug methods deleted.
</objective>
