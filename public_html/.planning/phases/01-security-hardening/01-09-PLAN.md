<!-- Same canonical replacement pattern as plan 08 -->

BEFORE (all occurrences follow this structural pattern):
```php
->where("(col1 LIKE '%" . $var . "%' OR col2 LIKE '%" . $var . "%')", NULL, FALSE)
```

AFTER:
```php
->group_start()
->like('col1', $var)
->or_like('col2', $var)
->group_end()
```

Single-column variant:
```php
// BEFORE: ->where("col LIKE '%" . $var . "%'", NULL, FALSE)
// AFTER:  ->like('col', $var)
```

CRITICAL: Never use array form `$this->db->like(['col1' => $v, 'col2' => $v])` — it produces AND, not OR.

To find occurrences in each file:
grep -n "NULL, FALSE" {file}
