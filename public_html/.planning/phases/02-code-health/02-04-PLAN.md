<objective>
Remove all 7 `error_reporting(0)` call-sites from 6 controller files (BUG-06).

Purpose: Per-method error suppression hides real PHP notices and warnings from developers. When Finance PDF generation, patient billing, or discharge flows fail silently, this is the mechanism masking those failures. CI3's `ENVIRONMENT` constant in `index.php` already controls error display correctly — development shows all errors, production hides them. The per-method suppressions are redundant and harmful.

Output: `error_reporting(0)` deleted from all 7 locations across 6 files. No replacement code needed — CI3 ENVIRONMENT handling is already in place.

Note: Wave 2 placement ensures this runs after all Wave 1 plans complete. The Finance.php changes here (removing error_reporting at lines 2942/3182) are safe to apply even though Settings.php was also modified in plan 02-03 — there is no file overlap conflict.
</objective>
