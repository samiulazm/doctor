<objective>
Fix BUG-04 (die() in Api::addAppointment) and BUG-05 (timezone file-write in Home.php and Settings.php).

Purpose:
- BUG-04: `addAppointment()` at Api.php:904 uses `echo $ion_user_id; die()` — a bare integer and hard termination. API callers get malformed output. Replace with proper JSON response and `return`.
- BUG-05: `updateTimezone()` in Home.php calls a `timeZone()` helper that opens `index.php`, writes an `ini_set()` call into it, and renames the temp file back. This is a runtime file-write to the web root — fragile, race-condition-prone, and unnecessary. The `required.php` hook already applies `date_default_timezone_set()` from DB at boot. Remove the entire file-write block from both Home.php and Settings.php.

Output:
- Api.php: `echo $ion_user_id; die();` → `echo json_encode(['success' => true, 'appointment_id' => (int)$ion_user_id]); return;`
- Home.php: `$this->timeZone($timezone);` call removed from `updateTimezone()`; entire `timeZone()` function body deleted
- Settings.php: duplicate `timeZone()` function deleted
</objective>
