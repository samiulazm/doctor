<!-- Migration target — exact API replacements from official phpspreadsheet migration guide -->

Old API (PHPExcel):
```php
// Autoloader — remove this line from Import.php constructor:
$this->load->library('Excel');

// File load:
$object = PHPExcel_IOFactory::load($file);

// Column index (0-based):
$highestColumn = PHPExcel_Cell::columnIndexFromString($highestColumnLetter);
for ($column1 = 0; $column1 < $highestColumn; $column1++) {
    $rowData1[] = $worksheet->getCellByColumnAndRow($column1, 1)->getValue();
}
for ($column = 0; $column < $highestColumn; $column++) {
    $rowData[] = $worksheet->getCellByColumnAndRow($column, $row)->getValue();
}
```

New API (PhpSpreadsheet — 1-based):
```php
// Namespace imports at top of file (after <?php):
use PhpOffice\PhpSpreadsheet\IOFactory;
use PhpOffice\PhpSpreadsheet\Cell\Coordinate;

// File load:
$spreadsheet = IOFactory::load($file);

// Column index (1-based):
$highestColumn = Coordinate::columnIndexFromString($highestColumnLetter);
for ($column1 = 1; $column1 <= $highestColumn; $column1++) {
    $rowData1[] = $worksheet->getCell([$column1, 1])->getValue();
}
for ($column = 1; $column <= $highestColumn; $column++) {
    $rowData[] = $worksheet->getCell([$column, $row])->getValue();
}
```

Key differences to apply everywhere:
1. `PHPExcel_IOFactory::load()` → `IOFactory::load()`
2. `PHPExcel_Cell::columnIndexFromString()` → `Coordinate::columnIndexFromString()`
3. `getCellByColumnAndRow($col, $row)` → `getCell([$col, $row])`
4. Loop start: `$column = 0` → `$column = 1`
5. Loop condition: `$column < $highestColumn` → `$column <= $highestColumn`
