legacy `id="editable-sample"` client-side DataTables to server-side `id="dt-{module}"` DataTables.

Purpose: The most-used list views in the system (doctors view their appointment list dozens of
times per clinic session). Server-side pagination eliminates full-table loads.

<!-- Standard datatables() controller method (source: 03-RESEARCH.md Pattern 1): -->
```php
public function datatables()
{
    $draw      = $this->input->post('draw');
    $start     = $this->input->post('start');
    $length    = $this->input->post('length');
    $search    = $this->input->post('search')['value'];
    $order_col = $this->input->post('order')[0]['column'];
    $order_dir = $this->input->post('order')[0]['dir'];

    $columns = ['id', 'name', /* module-specific columns */];
    $order   = isset($columns[$order_col]) ? $columns[$order_col] : 'id';

    if ($search) {
        $total    = count($this->module_model->getBySearch($search, $order, $order_dir));
        $filtered = $total;
        $records  = $this->module_model->getByLimitBySearch($length, $start, $search, $order, $order_dir);
    } else {
        $total    = count($this->module_model->getWithoutSearch($order, $order_dir));
        $filtered = $total;
        $records  = $this->module_model->getByLimit($length, $start, $order, $order_dir);
    }

    $data = [];
    foreach ($records as $row) {
        $data[] = [
            'id'      => $row->id,
            'name'    => htmlspecialchars($row->name ?? '', ENT_QUOTES, 'UTF-8'),
            'status'  => '<span class="ap-status ap-status-success">' . htmlspecialchars($row->status ?? '', ENT_QUOTES, 'UTF-8') . '</span>',
            'actions' => '<div class="ap-row-actions">'
                       . '<a href="#" class="ap-icon-btn" title="Edit" onclick="editRecord(' . (int)$row->id . ')"><i class="fas fa-edit"></i></a>'
                       . '<a href="#" class="ap-icon-btn text-danger" title="Delete" onclick="confirmDelete(' . (int)$row->id . ')"><i class="fas fa-trash"></i></a>'
                       . '</div>',
        ];
    }

    echo json_encode([
        'draw'            => (int) $draw,
        'recordsTotal'    => $total,
        'recordsFiltered' => $filtered,
        'data'            => $data,
        'csrf_hash'       => $this->security->get_csrf_hash(),
    ]);
}
```

<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Browser DataTables POST → datatables() controller | POST body contains draw/start/length/search/order from DataTables — all user-controlled |
| datatables() → model getBySearch() | search[value] is passed to model — must use $this->db->like() |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-03-04-01 | Tampering | SQL injection via search[value] in new model methods | mitigate | `$this->db->like()` mandatory; never string concatenation — CLAUDE.md non-negotiable; specific to Patient_model (line 65 known injection) |
| T-03-04-02 | Tampering | XSS in datatables() action column HTML | mitigate | `htmlspecialchars($row->field, ENT_QUOTES, 'UTF-8')` on all user-controlled strings in data[] array |
| T-03-04-03 | Information Disclosure | Cross-tenant data in datatables() response | mitigate | `$this->db->where('hospital_id', $this->session->userdata('hospital_id'))` in every model method |
</threat_model>
