<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Browser DataTables POST → datatables() controller (all modules) | search[value] is user-controlled input from the search box |
| datatables() → model getBySearch() | search string passed to model query — SQL injection vector |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-03-05-01 | Tampering | SQL injection via search in all new model methods | mitigate | `$this->db->like()` mandatory across all 66+ new model methods — enforced by CLAUDE.md; test suite would catch string interpolation at code review |
| T-03-05-02 | Information Disclosure | Cross-tenant data leak in bulk-added model methods | mitigate | Every model method includes `$this->db->where('hospital_id', $this->session->userdata('hospital_id'))` — zero exceptions |
| T-03-05-03 | Tampering | XSS in datatables() action HTML (bulk-added) | mitigate | `htmlspecialchars(..., ENT_QUOTES, 'UTF-8')` on all user-data fields rendered in data[] array |
</threat_model>
