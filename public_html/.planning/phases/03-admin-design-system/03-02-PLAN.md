- `class="badge badge-success ..."` — replace the `badge badge-success` portion, preserve any additional classes

Do NOT touch:
- `.badge` references in CSS files
- Comments referencing badge class names
- Any Bootstrap badge usage that is NOT a status indicator (e.g., notification count badges — these will be `badge badge-primary`, `badge badge-secondary`, etc. — only the four semantic status variants are in scope)
- The word "badge" in JavaScript strings that don't contain the four status variants

correct it to the right semantic class. For example: if a view has `badge-success` for
